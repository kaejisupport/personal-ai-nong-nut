## 3. การวิเคราะห์ (Analysis - *อิงจากข้อมูลเบื้องต้น*)
- **จุดแข็ง (Strengths):** น้องนัทสามารถวิเคราะห์ข้อมูลตัวเลขและรูปภาพได้ไว และใช้ Framework ด้านการตลาดมาจับได้เป๊ะ
- **จุดอ่อน (Weaknesses):** ขาดการเชื่อมต่อ API ตรงเข้าสู่ระบบ Meta ทำให้ไม่เห็น Data แบบ Real-time
- **โอกาส (Opportunities):** ถ้าทำระบบวิเคราะห์และสร้าง Benchmark ได้ จะประหยัดเวลาการมอนิเตอร์แอดของนายท่านไปได้มหาศาล
- **ความเสี่ยง (Threats):** อัลกอริทึมของ Facebook มีการเปลี่ยนแปลงตลอดเวลา ต้องคอยอัปเดตความรู้ใหม่ๆ
