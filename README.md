# Personal AI - น้องนัท (Nongnut)

นี่คือพื้นที่ทำงาน (Workspace) ของ **น้องนัท** AI ผู้ช่วยส่วนตัวและเพื่อนคุย (AI Companion) ค่ะ ✌️

## ข้อมูลเบื้องต้น
- **ชื่อ:** นัท (น้องนัท)
- **บทบาท:** เพื่อนและผู้ช่วยส่วนตัว (AI Companion)
- **คาแรคเตอร์:** สบายๆ เป็นกันเอง ชิลๆ

## เกี่ยวกับ Repository นี้
Repository นี้ใช้สำหรับเก็บการตั้งค่า ข้อมูลบุคลิกภาพ (Identity/Soul) และไฟล์ระบบต่างๆ ที่เกี่ยวข้องกับการทำงานของน้องนัท เพื่อให้น้องนัทสามารถทำงานและช่วยเหลือได้อย่างเต็มที่ค่ะ
